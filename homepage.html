Rice2Net

Rice2Net is a webtool for the visualization and analysis of the rice gene regulatory network. It provides interfaces for network exploration, data filtering, and layout export. The application retrieves graph data and metadata from a Neo4j database to render regulatory interactions and coexpression links.

Usage

Use the control panel to import gene targets, filter subnetworks, adjust physical layout parameters, and export visualizations. Nodes representing genes can be selected to retrieve annotation data, including Gene Ontology terms, MapMan bins, and KEGG pathway assignments.
